# The Production Engineering Handbook

An interactive, book-style website teaching production software engineering, networking, application security, Linux server administration, containers and Kubernetes, AWS, databases, system design, CI/CD, observability and the Forward Deployed Engineer playbook, from first principles to production.

Everything runs locally in the browser. There is no backend, no build step and no paid service.

## Run it

Browsers block `fetch()` of local files, so serve the folder over HTTP:

```bash
python3 -m http.server 8080
# or: npx serve .
```

Then open <http://localhost:8080>.

Any static host (S3 + CloudFront, GitHub Pages, Netlify, Nginx) works too: upload the folder as-is.

## Layout

```
index.html              application shell
css/style.css           typography, themes, layout, components
js/app.js               router, navigation, markdown pipeline, search, progress, bookmarks
js/components.js        interactive diagrams, step-through flows, layers, quizzes, checklists, scenarios, tabs
js/widgets.js           calculators: CIDR, chmod, JWT inspector, hashing, capacity, latency budget, SLO, AWS cost
content/curriculum.json parts and chapters (drives navigation and routing)
content/glossary.json   terms shown as tooltips and on the glossary page
content/search-index.json  generated by tools/build_index.py
content/pXX/cYY.md      one Markdown file per chapter
vendor/                 marked (Markdown) and highlight.js, vendored for offline use
```

## Authoring chapters

Chapters are Markdown with a few extensions:

- Callouts: `:::note Title` … `:::` with kinds `note`, `tip`, `warning`, `danger`, `security`, `cost`, `fde`, `vulnerable`, `secure`, `objectives`, `prereq`, and `details` (collapsible).
- Glossary tooltips: `[[term]]` or `[[term|display text]]`.
- Interactive blocks as fenced code with a language of `diagram`, `flow`, `layers`, `quiz`, `scenario`, `compare` (JSON), `checklist` or `tabs` (text), and `widget:<name>` for calculators.
- Cross-chapter links: `[text](#/p02/c07)`; links to a heading in the same chapter: `[text](#heading-slug)`.

After editing content run:

```bash
python3 tools/build_index.py
```

which regenerates the search index and word counts.

## Progress and privacy

Reading progress, bookmarks, quiz answers, checklist state and the theme are stored in `localStorage` in your browser only. Nothing is sent anywhere.
